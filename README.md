# IELTS Practice Test

A responsive IELTS practice test website built using HTML, CSS, and JavaScript.

The project is designed as a web programming practice project while recreating the structure and functionality of an online IELTS test interface.

## 🚀 Features

- IELTS-style test layout
- Listening test section
- Audio player
- Fill-in-the-blank questions
- Multiple-choice questions
- Automatic answer checking
- Automatic score calculation
- Responsive design
- Clean and simple user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
